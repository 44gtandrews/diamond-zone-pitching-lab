20–80 Scouting Scale

AGE-BASED GRADES

Grades are assigned by a coach relative to pitchers in the same age group—not to professional players. A 50 Grade means average for that age; higher is better. Where counts are available, pitches below are ordered by usage, highest first.

Grades are coach-assigned, not calculated automatically from velocity. “Not graded” means no scouting grade has been saved for that pitch.

          Account Permissions

          Admins manage accounts and data. Pitching Coaches can upload Trackman and edit coaching notes. Coaches can view all players without edits. Players/Parents see only the single linked player you select. Admin access for another person should be used only as an emergency backup.

            Inactive profiles are removed from the Internal and External directories and kept here with their pitching data, coaching notes and existing six-digit IDs. Reactivate them anytime.

              Emergency data backup and restore

              Download a private JSON snapshot of all players, linked six-digit IDs, coaching notes, grades, coach approvals and requests. Keep backups in a secure location.

              Restoration can overwrite existing records. Review the file and type RESTORE before proceeding. Existing records absent from the file are not deleted.

              Legacy roster-only tools

              Administrators manage private backups, account roles and player records. Pitching Coaches can add players, upload Trackman sessions and edit coaching notes. Coaches and Player/Parent accounts have read-only access appropriate to their roles.

              To create a player from a Trackman PDF, use + Add Player · Upload File above. This admin-only field accepts the private roster backup JSON only.

              New-coach text alerts

              Optional SMS notifications can be enabled securely through Firebase Cloud Functions and an SMS provider. No phone number or messaging credentials are stored in the website.
